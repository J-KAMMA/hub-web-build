# gltf-guard

持ち込みの `.glb` を検める。

**走査器はマルウェアを見るが、glTF そのものの罠は見ない。** MetaDefender を通っても、
次のものは素通りする。

| 罠 | 何が起きるか |
| --- | --- |
| 実際と食い違う長さを名乗る | 読む側が範囲外を読む |
| 元の入れ物をはみ出す参照 | 同上。glTF でいちばん多い |
| 外の場所を指す `uri` | 開いた人の browser が、こちらの知らない所へ取りに行く |
| 圧縮拡張（Draco / meshopt / KTX2） | **解く器がそのまま攻撃面**になる |
| 桁外れの頂点数・テクスチャ量 | 同じ区画に居る全員の画面が落ちる |

## 使う

```js
import { inspect, clean, WORLD_BUDGET } from "@jkamma/gltf-guard";

const seen = inspect(bytes);           // 通るか、通らない理由
const done = clean(bytes);             // 通ったものを書き直す
```

**書き直すのが要点。** 検めを通っても、知らない項目や塊の詰め物に何かが残っている
ことはある。**受け取ったバイト列をそのまま配らない。**

手元で確かめる:

```
node packages/gltf-guard/src/check.js model.glb
node packages/gltf-guard/src/check.js --write world.glb model.glb
```

## 予算

`WORLD_BUDGET` は**置かれる物1つ**の上限で、区画そのものより軽い。実測で、彫った街が
57,476 頂点、道路が 73,992。置かれる物1つがそれに並ぶと、立っている街より重い物が
道端にあることになる。

## できないこと

**見えているものは守れない。** 描く以上、頂点は見る人の機械へ渡る。ここで守るのは
売り物そのもの（元のファイル、素材、変種、高精細の版）であって、画面に映る形ではない。
出す人にそれを伝えないまま「守られる」と思わせてはいけない。
